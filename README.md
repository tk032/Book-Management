# Book Management

KT AIVLE School 4차 미니프로젝트 — Spring Boot와 React를 활용한 도서 관리 및 AI 표지 생성 시스템

---

## 프로젝트 개요

도서 정보를 등록하고 관리하는 풀스택 웹 애플리케이션입니다.
DALL-E 3 API를 연동하여 도서 제목과 내용을 기반으로 AI 표지 이미지를 자동 생성하는 기능을 포함합니다.

## 실행 방법

**백엔드**
```bash
cd backend
./gradlew bootRun
```

**프론트엔드**
```bash
cd frontend/bookmanage
npm install
npm start
```
